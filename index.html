03 — Architecture

Engineered for high-velocity capture.

No accounts. No sync spinners. No subscription wall. Four subsystems working at native speed, built with first-principles simplicity that will stay blisteringly fast forever.

01 / Universal Link Intelligence

Instant share-sheet ingestion

Share any link from Chrome, YouTube, X, Reddit, or Instagram. MomoStack resolves OpenGraph metadata, high-res posters, estimated read times, and topic tags inside sub-100ms background workers — then strips every tracker before a single byte is written.

02 / On-Device OCR

Screenshot intelligence

Every saved screenshot is indexed locally by ML Kit neural models. Search receipts, terminal logs, and slide decks like text — with zero frames leaving the device.

03 / Scratchpad

1-tap copy notes

Zero-friction note list with instant clipboard access, a full-screen focus editor, and category tagging. Keystrokes land with zero sync latency.

04 / Offline Permanence

Link intelligence & offline PDF archival

Long-press any saved card for deep contextual actions: render the page into an immutable, searchable offline PDF; copy the clean URL with tracking stripped; or re-file it across 13 topic vaults. Web pages rot — your archive doesn't.

07 — Questions

Frequently asked.

Only once per capture, if you want OpenGraph metadata like titles and posters resolved for a fresh URL. Every other operation — searching, OCR, note editing, reading offline PDFs, re-filing vaults — runs entirely offline. Airplane mode is not a degraded mode; it is the intended mode.
Nothing. Your vault is a plain SQLite database inside your app's private storage, with no server-side component, no proprietary sync format, and no account tether. The app keeps working forever, APK or not — and because MomoStack is MIT-licensed, anyone can fork and continue it indefinitely.
A deny-list of known surveillance parameters — utm_*, fbclid, gclid, share tokens, and affiliate hashes — is applied to every inbound URL before persistence. The clean canonical form is what gets stored, shared, and archived. You can inspect the full list on the Zero-Telemetry page.
The database lives in /data/data/org.momo.linkvault/, sandboxed by Android kernel UIDs so no other app can touch it without root. On Android 8+ the sandbox plus optional full-disk encryption covers data at rest. MomoStack deliberately requests no storage permission, so there is no shared-storage surface to leak from.
