1. Quickstart & Installation

MomoStack is distributed as an independent APK package. No Google Play account or Google Play Services framework is strictly mandatory.

  1. Download the official signed release from the Download Hub.
  2. Tap the APK notification on your Android device to install. If prompted, toggle "Allow from this source" in system settings.
  3. Verify the SHA-256 checksum to guarantee file authenticity.
  4. Launch MomoStack. You'll be greeted by Momo with zero mandatory account forms.
ADB Installation Command: adb install -r momostack-v1.0.apk

2. Android Share Sheet Ingestion Workflow

MomoStack registers an intent filter for android.intent.action.SEND with MIME type text/plain.

How to Capture in Under 1 Second:

When viewing any article in Chrome or watching a video on YouTube, tap Share → MomoStack. A subtle confirmation pill confirms capture, and the app instantly parses the title, description, and high-res thumbnail in the background.

Pro Tip: Pin MomoStack to your Android Share Sheet favorites so it appears as the first choice next to messaging apps.

3. On-Device OCR Recognition & Transcription

The OCR module uses on-device Google ML Kit models to extract text from images without network calls:

  • • Screenshots Tab: Switch to the Screenshots tab in MomoStack.
  • • Import Image: Tap "+" to select a screenshot from your device gallery.
  • • Automatic Indexing: The image is parsed in under 200ms and added to the searchable index.
  • • Searchable: Any text inside that image—error codes, Wi-Fi passwords, addresses—is now instantly findable via the search bar.

4. Offline Web Archival & PDF Snapshots

Articles on the web frequently get moved or deleted. MomoStack includes an on-demand PDF snapshot engine:

  1. Long-press on any link card in your feed.
  2. Select "Archive as Offline PDF" from the bottom action sheet.
  3. MomoStack loads the clean article view into Android's native print rasterizer and outputs a standardized PDF file stored in your private local directory.
  4. You can now read this full article anytime without internet access.

5. Frequently Asked Questions

Will my data sync across multiple phones?

By design, MomoStack v1.0 is 100% offline-first and contains no third-party cloud sync servers. You can export your SQLite vault file directly and restore it onto any other Android device.

Does MomoStack drain battery in the background?

No. MomoStack does not run persistent background socket connections, location polls, or heartbeat timers. Metadata parsing runs in short-lived Android WorkManager tasks that sleep as soon as resolution finishes.
