Verified Architecture Manifest

Zero Telemetry. Forever.

Most note-taking and bookmarking apps build behavioral profiles from your reading habits. MomoStack doesn't even own a server to send your data to.

The Carmack First-Principles Rule of Local Software

"If an application does not require a remote server to execute its fundamental promise, maintaining a remote server is an architectural defect, an unnecessary cost center, and an existential privacy risk to the user."

1. Telemetry & Tracker Elimination

MomoStack is compiled with zero analytical dependencies. You can inspect the source code, examine network traffic via Wireshark/Charles Proxy, or decompile the release APK:

  • ✕ No Google Firebase Analytics: Zero user tracking, event logging, or app session profiling.
  • ✕ No Mixpanel / Amplitude / Segment: Zero telemetry beacons or user journey funnels.
  • ✕ No Third-Party Advertising SDKs: 100% ad-free forever.
  • ✕ No Remote User Account System: No passwords, no auth tokens, no database leaks.

2. Local SQLite Sandbox Storage

Every single saved bookmark, extracted OCR text block, category structure, and private note is persisted in Android's isolated app container:

/data/data/org.momo.linkvault/databases/momo_vault.db

This directory is sandboxed via Linux kernel user IDs (UIDs). Other Android apps cannot read, inspect, or modify your database without root privileges.

3. Android Permissions Transparency

Permission Strict Scope & Purpose
android.permission.INTERNET Used only when you save a URL or initiate offline PDF archival to download the targeted webpage and its OpenGraph metadata. Never sends outbound telemetry.
android.permission.READ_MEDIA_IMAGES Allows the user to select screenshots from their gallery for on-device OCR transcription. MomoStack never accesses photos without explicit user selection.
Contacts, Mic, Location, Camera NEVER requested. Zero access.

4. Built-In Surveillance Parameter Stripper

When you share a link from Instagram or Twitter, it usually carries invasive tracking tokens:

https://example.com/article?utm_source=twitter&utm_medium=social&fbclid=IwAR2...

MomoStack's URL Engine strips all known advertising tracking queries before persistence:
